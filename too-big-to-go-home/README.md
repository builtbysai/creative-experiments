# Too Big To Go Home

A layered procedural rebuild (p5.js, single self-contained HTML file) of an AI-generated artwork — built one layer at a time, each researched against the original before coding.

## Layers so far

1. Asante kente background (6 sewn strips, warp-stripe sections, named weft blocks, 8 adinkra shapes)
2. Carved wood picture frame + hand-painted bottom title plaque
3. Painted desert sand with wavy horizon
4. Afrocentric woven cactus (Euphorbia-style textile sculpture)
5. Generative sun with spiral brushwork and triangular rays
6. Round thatched hut with conical layered-thatch roof

Still to come: the giant woven figure and the child shadow it casts.

## Pages

- **index.html** — current state (hut with Ndebele painted band)
- **hut-plain.html** — alternate variant: plain ochre hut walls, no painted band. Compare the two before the next layer begins.
