# Too Big To Go Home

A layered procedural rebuild (p5.js, one self-contained HTML file) of an AI-generated artwork, built one layer at a time.

Layers: Asante kente background (6 sewn strips, named weft blocks, 8 adinkra shapes), carved wood frame with a hand-painted title plaque, desert sand, woven cactus, a generative Afrocentric sun, the thatched hut, and the giant woven figure sitting grounded in its own contact shadow.

One reload in a thousand shows the original reference image instead of the re-creation.
